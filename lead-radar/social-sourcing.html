社媒挖掘工作台

从公开内容里找「刚起步、要贴牌、单量不大」的运动品牌，并把联系方式整理成可跟进的结构化表。

!
先把边界说清楚：这套流程不抓粉丝列表、不导评论区个人账号、不猜邮箱群发。

原因很实际：粉丝和评论者里绝大多数是消费者或同行，采购负责人几乎不会在评论区留工作邮箱；批量抓取还会触发平台风控，账号先被封。真正能落地的路径是——用内容找到品牌 → 回到官网/主页拿到企业自己公布的联系方式 → 用一句话确认对方是否负责采购。下面所有检索式、字段和模板都围绕这条路径设计。

批量抓取粉丝 / 关注列表 导出评论区个人账号 用私人号加好友、群发 DM 拼接猜测 Gmail 后群发

三、评论区、视频、关注列表到底怎么用

这些地方不产出联系方式，但产出高质量的「需求信号」和「品牌名单」——把它当线索层，不要当名单层
来源能提取到的信号下一步动作不要做
品牌自己视频的评论区 品牌方回复里常出现 "we produce in small batches"、"our factory in…"、"restocking soon"；这类自述就是 OEM 证据 截图/记下原话与链接，写进 oem_evidence，再回官网找 Wholesale 页 不追着评论者要联系方式
测评 / 开箱视频 视频里 @ 到的新兴品牌、被对比的小众品牌，往往就是刚起步、正在找供应链的那批 把品牌名收集起来，逐个查 bio 里的官网，再走官网邮箱 不把博主本人当客户
TikTok 文案里的 "DM for wholesale" 明确 B2B 意图，说明对方已经在做批发或贴牌 走 bio 邮箱或 TikTok Shop 客服，问「你们现在压缩裤是哪家在做」 不用小号批量私信
Facebook 群组「求供应商」帖 最真实的采购需求：数量、品类、交期常常直接写在帖子里 看发帖人的公司 Page，走 Page 公开邮箱；群里公开回复也可 不导出群成员、不群发
关注列表（只看品牌关注了谁） 品牌关注了哪些面料商、代工厂、展会账号，能判断它的供应链成熟度 作为评分参考（OEM 证据项），不导出成员 不抓取、不批量导出
跑团 / 赛事活动帖的 @ 名单 参与品牌、赞助品牌、联名方，通常是本地小而美的牌子 按国家整理成候选池，回官网核验品类与规模 不私信活动参与者
一句话原则：内容平台负责「发现谁在动」，企业官网 / 企业主页负责「怎么联系」。两者分开，既拿得到联系方式，也不会把账号做废。

四、目标客户筛选标准（100 分制）

重点不是「他卖不卖运动服」，而是「他有没有贴牌需求 + 单量是否匹配你的起订量」
维度分值加分证据（看到这些才给分）扣分 / 排除
品类契合25在售压缩裤/紧身裤/跑步背心；产品图与你的工艺同类只卖鞋、配件、休闲服 → 0–5
品牌阶段15独立品牌、成立 1–5 年、团队 <50 人、SKU <40大型集团自建供应链 → 0–3
OEM 证据20自述 "made in Portugal/China"、"private label"、"our factory"、联名款、限量补货、预售纯 drop-shipping 无品牌 → 0
单量匹配15小批量 drop、单色单码、pre-order、只做 3–5 个 colorway只做超大批量集采 → 5 以下
内容活跃10近 90 天有上新、跑团活动、赛事合作停更 >12 个月 → 0
决策人可触达10官网有 founder 署名、LinkedIn 能找到创始人/采购只有客服机器人 → 2
证据强度5信息来自官网/官方主页，日期可查只有搜索摘要 → 1
硬性保留条件（全部满足才进客户池）
· 有独立品牌名与可访问官网/店铺
· 在售品类与你至少 1 个 SKU 重合
· 能找到企业公开的业务联系方式
· 可判断为独立经营实体（非代购、非平台聚合页）
硬性排除（命中任一即放弃）
· 年营收 > 5 亿或员工 > 500 的大品牌（自建供应链）
· 纯代购 / 转售 / 无自有品牌
· 同类工厂或贸易商（竞争者）
· 只有个人账号、无企业主体
· 拒绝批发、只做零售单品的博主店
80 分以上：直接进首触达队列  |  65–79：补一条证据再决定  |  65 以下：不进池，不要为了凑数降低门槛。

五、联系方式整理的字段与格式

建议拆成两张表（公司表 + 联系人表），用 company_id 关联；不要把所有信息塞进一行，后面没法跟单
表字段类型 / 取值规则
公司表
companies		company_id文本，如 TH-0012国家码 + 序号，永不复用
brand_name / legal_name文本品牌名与法人名分开；法人名查不到就留空
country / cityISO 国家码 + 城市TH / Bangkok，不写「东南亚」这种模糊值
websiteURL规范化域名，不带参数
founded_year / employee_range年份 / 1-10、11-50…查不到写 unknown，不猜
products多值：compression_tights / singlet / tight_pants用固定枚举，便于筛选统计
oem_evidence文本 + 证据 URL写明看到的是哪一句（如 "made in Portugal"）
est_order_scaleS / M / LS=单款 <300 件，M=300–1000，L=>1000
score / status0–100 / qualified·review·rejected≥80 合格，65–79 待复核
first_seen / last_checkedYYYY-MM-DD超过 90 天未复核要标 stale
表字段类型 / 取值规则
联系人表
contacts		contact_id / company_id文本一个公司可多条联系人
person_name / title文本只写公开职业身份，不写私人信息
role_typefounder / purchasing / product / marketing决定首封信怎么写
email邮箱企业邮箱优先；个人邮箱仅在官网团队页公开时使用
email_statusconfirmed_on_source / pattern_inferred / not_found推测的一律标 pattern_inferred，不得当已确认
phone / whatsapp_business带国家码 / yes·no·unverified只记录企业公开号码；不推断是否开通 WhatsApp
line_id / kakao_channel / instagram / linkedin企业账号记录账号归属来源 URL
source_url / observed_atURL + 日期每个联系方式都要能点回去看
consent_basis / notes文本写清「官网公开」「展会名片」「对方主动提供」
格式约定：CSV 用 UTF-8 with BOM（Excel 直接打开不乱码）；日期统一 YYYY-MM-DD；多值字段用英文分号 ; 分隔；一条记录一行，不要在单元格里换行。

六、7 天跑完第一批（目标 30 家合格客户）

按这个节奏，一个人一周能产出 30 家可跟进的公司，而不是 5000 条无主邮箱
DAY 1
建词表6 国 × 3 产品的本地语言词，落成检索词包
DAY 2
Google 扫官网高级检索跑 20 条式子，收 60 个独立站
DAY 3
IG / TikTok40 个 hashtag，找刚起步的品牌，记官网
DAY 4
取公开联系方式只从 About / Wholesale / Contact 页取
DAY 5
确认决策人LinkedIn 核对创始人/采购职务，不导出私人信息
DAY 6
打分排序按 100 分制筛出前 30，剔除硬排除项
DAY 7
首触达人工审 10 封，一封信只问一个问题
日配额建议：采集 60 家 → 合格 15–20 家 → 首触达 10–15 封。超过这个量，回复率会掉、账号风险会升，且你根本跟不过来。
关于「直接联系方式」：真正可直接使用的，是企业自己公布在官网、企业主页、展会资料上的业务邮箱/WhatsApp/LINE/Kakao。个人手机号、私人邮箱、粉丝与评论者账号不在可采集范围内，也不建议使用——这类名单的回复率通常低于 1%，还会让品牌方直接拉黑。
关于私信：给企业账号发 DM 可以，但一个品牌只发一次、只发给确认是品牌方的账号、内容必须与对方产品有关；对方未回复就停止，不换号追问。
本页不连接任何平台接口、不执行抓取与发送，只生成检索策略、筛选标准与数据结构。
