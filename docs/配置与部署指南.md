# LeadRadar 配置与部署指南（傻瓜版）

照着做即可，全程不需要改代码。三样东西配好：**搜索 key → 大模型 key → 代理**。不配也能跑（退化为"本地样本库官网挖联系方式"），配了才是真正的"AI 每天 10 点获客"。

---

## 一、你需要 3 样东西

| 东西 | 作用 | 推荐 | 成本 |
|---|---|---|---|
| ① 搜索 key | 搜出**新客户** | Serper | $50 约 5000 次（约 ¥0.07/次） |
| ② 大模型 key | AI 判断 + 写开发信 | DeepSeek | 极便宜，几块钱用很久 |
| ③ 代理 | 访问 Instagram/TikTok | 你现有的梯子 | 已有 |

**填法只有两种，任选其一：**
- **A. `.env` 文件（推荐）**：复制 `.env.example` 为 `.env`，填进去。`.env` 已被 gitignore，不会泄露。
- **B. `config.json`**：直接改 `config.json`（但 `config.json` 已 gitignore，不会被提交）。

> 推荐用 A。下面的步骤都按 A 写。

---

## 二、配 ① 搜索 key（Serper，推荐）

1. 打开 https://serper.dev ，点 **Sign up** 用 Google 账号登录。
2. 登录后进 **Dashboard**，顶部直接给你一个 `API Key`（`xxxx...`）。
3. 免费额度：注册送一部分；正式用充值 $50 起。
4. 填入 `.env`：
   ```
   SERPER_API_KEY=你的key
   ```

> 备选（不想花钱 / 想白嫖）：
> - **Bing Web Search**（Azure 有免费层）：`.env` 填 `BING_API_KEY=xxx`，再把 `config.json` 里 `search.provider` 改成 `"bing"`。
> - **Google Custom Search**（每天 100 次免费）：填 `GOOGLE_CSE_KEY` 和 `GOOGLE_CSE_CX`，`search.provider` 改成 `"google_cse"`。

---

## 三、配 ② 大模型 key（DeepSeek，推荐）

1. 打开 https://platform.deepseek.com ，注册并登录（支持支付宝充值）。
2. 左侧 **API Keys** → **创建 API Key**，复制保存（只显示一次）。
3. 填入 `.env`：
   ```
   LLM_API_KEY=sk-xxxxxxxx
   ```
   默认已经是 DeepSeek 的地址和模型，无需改 `base_url`。

> 换别家（通义/智谱/Kimi/OpenAI）只改两行：
> ```
> LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1   # 以通义为例
> LLM_MODEL=qwen-plus
> ```

---

## 四、配 ③ 代理（访问 Instagram/TikTok）

国内直连 Instagram/TikTok 不通，需要代理。两种方式，**选更省事的一种**：

**方式一：开启"系统/全局代理"的 HTTP 端口（最省事）**
- Clash：设置里打开「系统代理」，默认端口 `7890` → `.env` 里填：
  ```
  HTTPS_PROXY=http://127.0.0.1:7890
  ```
- v2rayN / V2Ray：默认 `10808`（或 `1080`）→ 改端口即可。
- 或直接把代理地址填进 `config.json` 的 `"proxy"` 字段（效果一样）。

**方式二：开启"TUN 模式 / 全局模式"（最傻瓜）**
- Clash 的「TUN 模式」、v2rayN 的「全局路由」会把整台机器所有流量都走代理。
- 这种情况下**什么都不用填**，程序自动就走通了。

> 判断代理端口：打开你的代理软件，看「端口 / Port」设置项；Clash 常见 7890，v2rayN 常见 10808，SSR 常见 1080。

## 五、启动与验证

```bash
# 1. 装 Node（Windows / Ubuntu 都行，≥18）
node --version        # 能看到版本号即可

# 2. 看定时时间对不对（默认每天 10:00:00，可精确到秒）
node scheduler.mjs --next

# 3. 手动跑一次，看效果
node run.mjs
#    → 输出 out/<日期>/report.html（含客户、邮箱、电话、社媒、AI 开发信）

# 4. 开机自启（自动识别系统）
node scheduler.mjs --register-task
#    Windows：注册计划任务
#    Ubuntu：生成 leadradar.service，按提示执行 systemctl enable --now
```

改推送时间：编辑 `config.json` 的 `schedule.daily`（`HH:MM:SS`）。时区按 `schedule.timezone`（默认 `Asia/Shanghai` 北京时间），与服务器本地时区无关。

## 六、怎么确认"配好了"

| 现象 | 说明 |
|---|---|
| 报告数据源显示「Serper(Google)」 | ① 搜索 key 生效 |
| 日报里出现「AI 开发信草稿」 | ② 大模型 key 生效 |
| 日报里出现 instagram/tiktok 线索且带 bio 网站 | ③ 代理生效 |
| 报告数据源仍显示「本地样本库」 | ① 没配好，检查 key |

---

## 七、常见问题

1. **`未配置搜索 API key` 警告** → 说明 ① 没生效，检查 `.env` 里 `SERPER_API_KEY` 是否有值、是否拼错。
2. **开发信没有生成** → ② 大模型 key 没配好；看警告里的「未配置大模型 key」。
3. **社媒线索读不到 bio** → ③ 代理没生效；用 `curl -x http://127.0.0.1:7890 https://www.instagram.com` 测试代理是否通。
4. **`fetch` 报 proxy 错误** → `.env` 的 `HTTPS_PROXY` 端口写错了，换成你代理软件的实际端口。
5. **Ubuntu 服务器收不到通知** → 服务器无桌面，把 `config.json` 的 `report.webhook_url` 填成企业微信/钉钉机器人地址，每天自动推送到手机。

## 八、安全提醒

- 所有 key 只填 `.env`（已 gitignore），**不要**填进 `config.example.json` 或提交到 Git。
- 报告里挖到的邮箱/电话是公开信息；系统**只采集、不自动发信**，所有触达请人工确认。
- 社媒链路只做"公开主页线索发现"，不做批量私信、不抓粉丝列表（违反平台条款）。
